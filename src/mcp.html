Model Context Protocol (MCP)

Streamable HTTP · Stateless
MCP endpoint for AI agents (Claude Code, Claude Desktop, and other MCP clients). Provides read-only access to workspaces, projects, tasks, and notes.
Endpoint: POST /mcp — Bearer token authentication using a dedicated MCP token.
MCP is disabled by default. Enable it in the admin UI (/) under MCP Access to generate a token. Copy the token when it's shown (if you lose it, rotate the token).

Quick Start

Configuration
Step 1 — Enable MCP
Open the admin UI at /, sign in with the master token, then go to MCP Access and click Enable MCP. Copy the generated MCP token.
Step 2 — Claude Code (connect MCP)
click to copyclaude mcp add --transport http focus-compass http://localhost:8080/mcp \ --header "Authorization: Bearer YOUR_MCP_TOKEN"
Verify with claude mcp list — focus-compass should appear.
Claude Desktop / Other MCP Clients
Add the following to your MCP configuration file:
click to copy{ "mcpServers": { "focus-compass": { "type": "http", "url": "http://localhost:8080/mcp", "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" } } } }
Config file locations:
Claude Desktop: claude_desktop_config.json
Claude Code (project scope): .mcp.json in project root
Claude Code (user/local scope): ~/.claude.json

Available Tools

4 tools
All tools are read-only. Results are returned as JSON (in a text block).
list_documents read
List all documents (workspaces) with workspace name, project count, and last update time.
No parameters required
get_workspace read
Get workspace overview with projects, tasks and notes. The sections parameter controls which data is included.
document string, required
Document name from list_documents
sections object, optional
project_info (default: true), current_focus (true), next_tasks (true), completed_tasks (false), notes (false)
list_projects read
List projects in a document (IDs and titles). Use project_info to include descriptions/images/fields.
document string, required
Document name from list_documents
project_info boolean, optional
Include project descriptions, images and fields (default: false)
get_project read
Get a single project by ID with all tasks, focus groups, and notes. Returns available project IDs if not found.
document string, required
Document name from list_documents
project_id string, required
Project ID from list_projects

Skill

/focus-compass (optional)
Optional: install a Claude Code skill so you can type /focus-compass anywhere to get a concise overview of your projects, or ask questions like "what am I working on?".
Skill docs: code.claude.com/docs/en/skills
Skill template: http://localhost:8080/focus-compass-skill.md
One-liner install (MCP + Skill)
Run one command to add the MCP server and install the /focus-compass skill (replace YOUR_MCP_TOKEN):
click to copymacOS / Linux: claude mcp add --transport http focus-compass http://localhost:8080/mcp --header "Authorization: Bearer YOUR_MCP_TOKEN" && mkdir -p ~/.claude/skills/focus-compass && curl -fsSL http://localhost:8080/focus-compass-skill.md -o ~/.claude/skills/focus-compass/SKILL.md Windows (PowerShell): claude mcp add --transport http focus-compass http://localhost:8080/mcp --header "Authorization: Bearer YOUR_MCP_TOKEN"; New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude\skills\focus-compass" | Out-Null; Invoke-WebRequest "http://localhost:8080/focus-compass-skill.md" -OutFile "$env:USERPROFILE\.claude\skills\focus-compass\SKILL.md"
Alternatively, create a project-local skill at .claude/skills/focus-compass/SKILL.md in your current repo.
Skill only (if MCP is already configured)
Download the skill template separately:
click to copymacOS / Linux: mkdir -p ~/.claude/skills/focus-compass && curl -fsSL http://localhost:8080/focus-compass-skill.md -o ~/.claude/skills/focus-compass/SKILL.md Windows (PowerShell): New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude\skills\focus-compass" | Out-Null; Invoke-WebRequest "http://localhost:8080/focus-compass-skill.md" -OutFile "$env:USERPROFILE\.claude\skills\focus-compass\SKILL.md"
Usage
/focus-compass — overview of all projects
/focus-compass what am I working on? — current focus
/focus-compass show tasks for ProjectName — specific project details

Protocol Details

Streamable HTTP
Transport: Streamable HTTP (MCP spec 2025-03-26)
Mode: Stateless — no session tracking
Methods: POST /mcp only (stateless)
Content-Type: application/json (request/response; client still sends Accept: application/json, text/event-stream)
Auth: Bearer MCP token via Authorization header
Each request creates an independent server instance. No session state is maintained between requests.

click to copycurl -X POST http://localhost:8080/mcp \ -H "Authorization: Bearer YOUR_MCP_TOKEN" \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -d '{"jsonrpc":"2.0","id":2,"method":"tools/call", "params":{"name":"list_documents","arguments":{}}}'
